# Skills

这里存放可复用 Codex skills。标准结构：

```text
skills/
  <skill-name>/
    SKILL.md
    references/
    assets/
```

## 目录说明

- `ai-growth-counselor/`：AI 技能成长辅导员 skill。
- `_drafts/`：尚未定稿、暂不投入长期使用的 skill 草稿。

## 使用规则

1. 定稿 skill 使用 `skills/<skill-name>/SKILL.md`。
2. 草稿先放 `_drafts/`，确认可复用后再迁移到独立目录。
3. 大段参考资料放 `references/`。
4. 输出资产、模板或图片放 `assets/`。
