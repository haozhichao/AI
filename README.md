# AI Growth Workspace

这个仓库用于沉淀 AI 技能成长辅导、实践项目、复盘材料和可复用 skills。

## 顶层目录

- `ai-growth-counselor.md`：当前辅导员指南的根目录副本，便于快速查看。
- `skills/`：可复用 Codex skills，标准形态为 `skills/<skill-name>/SKILL.md`。
- `projects/`：可运行源码、实验项目、demo 和测试。
- `practice/`：学习日志、任务书、项目笔记、复盘、路线与作品化材料。

## 使用原则

1. skill 指南放 `skills/`。
2. 能运行的源码放 `projects/`。
3. 过程记录、任务书和复盘放 `practice/`。
4. 可展示成果从 `projects/` 和 `practice/` 收口到 `practice/06-portfolio/`。
