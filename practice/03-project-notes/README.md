# Project Notes

这里存放项目过程笔记、卡点、方案草稿和复盘材料。可运行源码放顶层 `projects/`。

## 子目录

- `rag/`：RAG 项目笔记。
- `agents/`：Agent 项目笔记。
- `mcp/`：MCP 项目笔记。
- `evals-observability/`：evals 与可观测性项目笔记。
- `workflow-automation/`：工作流自动化项目笔记。

## 使用规则

1. 任务拆解、失败记录、方案草稿放这里。
2. 源码、测试、脚本和 demo 放 `projects/`。
3. 每周复盘时，把可展示成果收口到 `practice/06-portfolio/`。
