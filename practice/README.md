# Practice Workspace

这个目录用于存放 AI 技能成长辅导过程中的实践材料。默认原则是：先放证据，再做复盘；先服务主线，再扩展副业。

## 目录说明

- `00-inbox/`：临时想法、未归类资料、随手记录。每周复盘时清理或归档。
- `01-logs/`：`learning-log.md`、每日三行日志、健康试验记录。
- `02-roadmap/`：当前主线、双周矫正、路线判断、方向决策。
- `03-projects/rag/`：RAG 实战、问答链路、检索评估。
- `03-projects/agents/`：Agent 实战、端到端任务、工具调用流程。
- `03-projects/mcp/`：MCP Server 雏形、协议练习、工具接入。
- `03-projects/evals-observability/`：evals、指标、日志、可观测性、防坏策略。
- `03-projects/workflow-automation/`：工作中重复任务的 AI 化改造。
- `04-task-briefs/`：给 Agent、Codex、Copilot 等工具的任务书。
- `05-reviews/`：每周复盘、阶段复盘、失败案例复盘。
- `06-portfolio/`：可展示成果、README 草稿、作品集材料。
- `07-side-work/`：低摩擦副业、小单需求、交付模板、范围控制。
- `99-archive/`：过期路线、废弃实验、历史材料。

## 存放规则

1. 当天实践优先落到 `01-logs/`、`04-task-briefs/` 或 `03-projects/`。
2. 每周复盘时，把可展示成果收口到 `06-portfolio/`。
3. 双周主线矫正放到 `02-roadmap/`。
4. 副业材料只有来自主线产出时，才放到 `07-side-work/`。
5. 不确定放哪里时，先放 `00-inbox/`，每周复盘时归类。

## 建议命名

使用日期前缀，方便排序：

```text
2026-10-29-learning-log.md
2026-10-29-agent-task-brief.md
2026-W44-weekly-review.md
2026-W44-mainline-correction.md
```
